# Cloud Native Labor – GitHub Pages

Komplex, 6 × 45 perces oktatói weboldal a **Szerverek és felhőszolgáltatások** tantárgyhoz.

## Témák
- GitHub Codespaces
- Docker image és container
- Dockerfile
- Docker Compose
- volume és hálózat
- Docker Hub
- Kubernetes Deployment és Service
- skálázás, self-healing, rollout
- GitHub Actions CI
- Cloudflare Pages

## Tartalom
- `index.html`
- `styles.css`
- `script.js`
- `downloads/cloudlab_starter.zip`
- `starter/` – a starter projekt kibontott fájljai

## GitHub Pages publikálás
1. Hozz létre egy új GitHub repositoryt.
2. A csomag teljes tartalmát töltsd fel a repository gyökerébe.
3. Settings → Pages.
4. Source: Deploy from a branch.
5. Branch: main.
6. Folder: /(root).
7. Save.

## Oktatói megjegyzés
A weboldal LocalStorage-ban menti a tanuló saját böngészőjében a haladást.
A külső szolgáltatások ingyenes keretei idővel változhatnak.
